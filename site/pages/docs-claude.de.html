Claude Code

VibeWorks ist ein MCP-Server. Claude Code (oder ein anderer MCP-Client) arbeitet damit direkt mit deinen Projekten, Aufgaben, Notizen und Docs – mit deinen Rechten.

Einrichten

  1. In VibeWorks unter Mein Konto → Claude Code & API-Schlüssel einen Schlüssel erstellen.
  2. Den angezeigten Einzeiler (Linux/macOS oder Windows) im Terminal ausführen – er trägt VibeWorks in Claude Code ein und legt die Agenten-Regeln als Skill ab. Von Hand sieht der Befehl so aus:
claude mcp add --scope user --transport http vibeworks https://vibeworks.example.de/api/mcp --header "Authorization: Bearer vw_…"

Mit --scope user gilt die Verbindung in allen deinen Repositories. Andere MCP-Clients verbinden sich per Streamable HTTP mit /api/mcp und demselben Header. Schlüssel lassen sich jederzeit widerrufen; gespeichert wird nur ein Hash.

Mit Gerätecode

KI-Programme mit Geräte-Anmeldung zeigen einen Code und die Adresse /verbinden. Dort anmelden, Code eingeben, prüfen, was das Programm nutzen darf, und erlauben – ein Schlüssel zum Kopieren entfällt. Codes gelten 10 Minuten.

Projekt-Schlüssel

Ein Schlüssel kann auf ausgewählte Projekte beschränkt werden, mit Ablaufdatum und Pause-Knopf. Auf der Projektseite unter Projekt-Schlüssel siehst du, wer Zugriff hat, und widerrufst ihn einzeln. Teammitglieder mit dem Recht Projekt-Schlüssel freigeben dürfen das auch.

KI-Workflows

Projektseite → KI-Workflows: Checklisten, die die KI Schritt für Schritt abarbeitet – jeder Schritt mit Prüfung, bevor der nächste kommt. Mitgeliefert sind „Feature umsetzen“, „Fehler beheben“, „Release vorbereiten“, „Projekt durchsehen“ und „Projektaufbau pflegen“; eigene legst du dazu. Solange ein Workflow läuft, erinnert VibeWorks die KI bei jedem Aufruf an den nächsten Schritt. In Claude Code stehen die Workflows auch als Befehle bereit.

Projektaufbau

Projektseite → Aufbau: eine Tabelle mit Bereich, Pfad, Zweck und Funktionsweise. Die KI legt sie mit update_project_structure an und hält sie aktuell; VibeWorks meldet Pfade, die es im Repository nicht mehr gibt, und schreibt die Tabelle in die Anleitung.

Anleitung für die KI

Projekt → Weitere Aktionen → KI-Anleitung erzeugen: Beschreibung, Stand, offene Aufgaben, angepinnte Notizen, Projektaufbau und die Arbeitsweise mit VibeWorks in einer Datei – als CLAUDE.md, AGENTS.md (Codex und andere), GEMINI.md, Copilot-, Cursor-, Windsurf- oder Cline-Regel. Anpassen, kopieren oder herunterladen und ins Repository legen – die KI liest sie bei jedem Start.

Prompt-Bibliothek

Unter Prompts sammelst du bewährte Anweisungen. Platzhalter wie {{projekt}}, {{repo}}, {{live}} und {{summary}} füllt ein gewähltes Projekt beim Kopieren aus. „Beispiele hinzufügen“ legt fünf Vorlagen an – vom Code-Review bis „Offene Aufgaben abarbeiten“.
