Claude Code

VibeWorks ist ein MCP-Server. Claude Code (oder ein anderer MCP-Client) arbeitet damit direkt mit deinen Projekten, Aufgaben, Notizen und Docs – mit deinen Rechten.

Einrichten

  1. In VibeWorks unter Mein Konto → Claude Code & API-Schlüssel einen Schlüssel erstellen.
  2. Den angezeigten Befehl kopieren und im Terminal ausführen – er sieht so aus:
claude mcp add --scope user --transport http vibeworks https://vibeworks.example.de/api/mcp --header "Authorization: Bearer vw_…"

Mit --scope user gilt die Verbindung in allen deinen Repositories. Andere MCP-Clients verbinden sich per Streamable HTTP mit /api/mcp und demselben Header. Schlüssel lassen sich jederzeit widerrufen; gespeichert wird nur ein Hash.

Was Claude damit kann

WerkzeugWas es tut
list_projects, get_projectProjekte mit Status, offenen Aufgaben, Notizen und Repository
list_tasks, get_taskAufgaben über alle Projekte – z. B. alles, was diese Woche fällig ist
create_task, update_taskAufgaben anlegen und nach „In Arbeit“ oder „Erledigt“ schieben – Issues laufen mit
create_task_in_projectsDieselbe Aufgabe in mehreren Projekten, ohne Angabe in allen mit Git
update_projectStatus, Priorität, Fortschritt, Kurzbeschreibung
create_note, get_noteNotizen am Projekt, z. B. ein Arbeitsprotokoll
searchVolltextsuche über Notizen, Aufgaben und Docs
list_docs, get_doc, create_doc, update_docDocs lesen und schreiben
get_claude_md, list_prompts, get_promptCLAUDE.md eines Projekts und deine Prompt-Bibliothek

Probier zum Beispiel: „Welche Aufgaben sind in VibeWorks offen?“ oder „Arbeite die offenen Aufgaben von Projekt X ab und halte fest, was du gemacht hast, als Notiz.“ Jede Änderung steht im Verlauf des Projekts.

CLAUDE.md erzeugen

Projekt → Weitere Aktionen → CLAUDE.md erzeugen: Beschreibung, Stand, offene Aufgaben, angepinnte Notizen und die Arbeitsweise mit VibeWorks in einer Datei. Anpassen, kopieren oder herunterladen und ins Hauptverzeichnis des Repositorys legen – Claude Code liest sie bei jedem Start.

Prompt-Bibliothek

Unter Prompts sammelst du bewährte Anweisungen. Platzhalter wie {{projekt}}, {{repo}}, {{live}} und {{summary}} füllt ein gewähltes Projekt beim Kopieren aus. „Beispiele hinzufügen“ legt fünf Vorlagen an – vom Code-Review bis „Offene Aufgaben abarbeiten“.
