Windows app

VibeWorks in its own window instead of a browser tab – with a tray icon, quick capture from any program and Windows notifications.

⬇️ Download VibeWorks-Setup.exe

Installing

  1. Run the installer. It isn't signed (yet) – if Windows says “Windows protected your PC”, click More info → Run anyway.
  2. On first start, enter your server's address, e.g. vibeworks.example.com – without https:// the app tries HTTPS first, then HTTP.
  3. Sign in as usual. The session is kept.

What the app does

FeatureHow
Quick captureCtrl+Alt+V from any program – idea or task, even for all projects at once. Esc closes it.
TrayIcon next to the clock: open, quick capture, notifications on/off, change server, updates, quit.
BackgroundClosing only hides the window – can be turned off in the tray menu.
NotificationsEverything from My account → Notifications arrives as a Windows notification; a click opens the matching page.
UpdatesThe app checks on start and every six hours and asks before restarting.

Tip: under My account → Notifications, “Send test” also tests the Windows notification – no other channel needs to be set up for that.
