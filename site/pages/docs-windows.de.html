Windows-App

VibeWorks im eigenen Fenster statt im Browser-Tab – mit Tray, Schnellerfassung aus jedem Programm und Windows-Benachrichtigungen.

⬇️ VibeWorks-Setup.exe herunterladen

Installieren

  1. Installer ausführen. Er ist (noch) nicht signiert – meldet Windows „Der Computer wurde durch Windows geschützt“, auf Weitere Informationen → Trotzdem ausführen klicken.
  2. Beim ersten Start die Adresse deines Servers eintragen, z. B. vibeworks.example.de – ohne https:// probiert die App erst HTTPS, dann HTTP.
  3. Wie gewohnt anmelden. Die Sitzung bleibt erhalten.

Was die App kann

FunktionSo geht's
SchnellerfassungStrg+Alt+V aus jedem Programm – Idee oder Aufgabe, auch für alle Projekte auf einmal. Esc schließt.
TraySymbol neben der Uhr: öffnen, Schnellerfassung, Benachrichtigungen an/aus, Server ändern, Updates, Beenden.
Im HintergrundSchließen versteckt das Fenster nur – abschaltbar im Tray-Menü.
BenachrichtigungenAlles aus Mein Konto → Benachrichtigungen kommt als Windows-Meldung; ein Klick öffnet die passende Seite.
UpdatesDie App prüft beim Start und alle sechs Stunden selbst und fragt vor dem Neustart.

Tipp: Unter Mein Konto → Benachrichtigungen testet „Test senden“ auch die Windows-Meldung – dafür muss kein anderer Kanal eingerichtet sein.
